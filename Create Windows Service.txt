========================
Step 1 - Build zk-agent.exe (pkg + sqlite3)
========================

npm install -g pkg

Do NOT add pkg-native/node_sqlite3.node to .gitignore — pkg skips gitignored files, so the native addon would be missing inside the exe.

Use Node 18 when syncing/rebuilding sqlite3 (same ABI as node18-win-x64, module 108):

  nvm use 18
  npm rebuild sqlite3
  npm run pkg:win

(pkg:win = sync-pkg-native + pkg). You must run pkg against the project (package.json), not production.js alone — otherwise "pkg".assets from package.json are ignored and the sqlite3 native file is not embedded:

  npm run sync-pkg-native && pkg . --targets node18-win-x64 --output zk-agent.exe

If you ever need a manual fallback: copy folder pkg-native (with node_sqlite3.node) next to zk-agent.exe — the bootstrap checks there too.

Output: zk-agent.exe
====================================================
Step 2 - Download nssm(Non-Sucking Service Manager)
====================================================

https://nssm.cc/download (Download the latest version)
Use 64-bit nssm.exe.
Keep nssm.exe and zk-agent.exe in same directory and run:

nssm install zk-agent

Add path and subdirectory such as:

Path: F:\Development\biometric\zk-agent.exe
Startup directory: F:\Development\biometric

Finally, click install service

You can also edit the path: 

nssm edit zk-agent

========================
Step 3 - Run Service
========================

Go Win + R and type services.ssc. locate zk-agent → start it.

sc failure "zk-agent" reset= 60 actions= restart/5000

In case you want to delete services file, use administrator privelges and run cmd command:


========================
Delete Service
========================

sc delete zk-agent
